
  # Design GebetaCloud ERP Website

  This is a code bundle for Design GebetaCloud ERP Website. The original project is available at https://www.figma.com/design/ikO9vyzt70nLKg5VaBh7Yc/Design-GebetaCloud-ERP-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  To start the frontend only, run `npm run dev`.
  To start the backend auth server, run `npm run server`.
  To run both at once during development, run `npm run dev:all`.
